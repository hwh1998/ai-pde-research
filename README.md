# PDE AI Copilot

AI-assisted research workflow for partial differential equations.

🔬 **Goal:** Build an end-to-end AI-human collaboration pipeline that covers:
- Symbolic derivation of PDE properties (e.g., local well-posedness for quasilinear hyperbolic systems)
- Automatic generation of numerical simulation code (FEniCS / DeepXDE)
- AI-assisted LaTeX manuscript drafting
